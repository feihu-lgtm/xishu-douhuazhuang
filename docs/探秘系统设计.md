# 探秘系统设计：维度 → 题干 → 选项 → 交互

对应地图重构后的「探秘」：玩家在地图上点一个据点，进去后不再是单次抽情境+直接给奖励，
而是一段可读、可选、可判定的小场景。本文档是这套系统的设计依据，代码 schema 见
`src/data.js` 的 `DIMENSIONS` / `EXPEDITION_TASK_TYPES` / `OPTION_ARCHETYPES`。

## 第一层：维度系统（出题的底层）

维度是玩家永远看不到的东西，只有引擎和 AI 知道这关在考什么。从 xiaochu 现有属性
（`st.skills`）扩展出 8 个维度，分四类：

| 维度 | 归属 | 题干会暗示什么 | 用谁判定 |
|---|---|---|---|
| 轻功 | 身法 | 崖壁、独木、浮桥、树梢 | 玩家 skills.轻功 |
| 投掷 | 身法 | 够不着的东西、暗器、勾索 | 玩家 skills.投掷 |
| 武艺 | 硬功 | 拦路的人/兽、需要硬碰 | 刀/剑/拳/枪取高者 |
| 内功 | 硬功 | 寒气、毒瘴、水底、暗劲 | 玩家 skills.内功 |
| 眼力 | 智谋 | 雾气、灰烬、药草、赝品 | 新增 skills.眼力 |
| 见识 | 智谋 | 认不得的兽迹、碑文、异味 | 新增 skills.见识（=百科） |
| 口才 | 心性 | 守门人、市侩、赌局 | 新增 skills.口才 |
| 胆识 | 心性 | 阴风、尸骸、深不见底 | 新增 skills.胆识 |

外加两个非常规维度：

- **资源**：靠包里的东西过（绳索/药/火折子/银钱），不检定，直接扣。
- **苏唐**：靠苏唐的手艺或好感过（协作维度）。

**抽取规则：**

- 每次探秘抽 2 个主维度（身法/硬功/智谋/心性四类里随机分布，保证类别不重复）+ 30%
  概率附加一个资源或苏唐作解法补充。
- 权重可调：玩家的薄弱维度会稍微更常被抽中（制造"这次正好卡我"的戏剧感），但留
  40% 完全随机。
- 抽完 → 把维度列表塞给 AI → AI 按维度出题。

## 第二层：文学化出题（玩家只看到题干）

铁律：题干里永不出现维度名、数值、成功率。玩家通过读句子猜"这关在考什么"，猜对了
就是元游戏乐趣。

AI 收到 `[轻功, 眼力]` 后的出题示例：

> 雨后的乱石滩漫起白雾。崖壁湿滑，藤蔓只够搭半只脚掌，你数了数能落脚的凸石，对岸
> 的药材就挂在突出的枯枝上。雾里影影绰绰，像是有什么东西在盯。

玩家读不出"轻功"和"眼力"，但感觉得到"要爬 + 要看"。选项就从这个题干长出来。

## 第三层：探秘任务类型（7 大类，按情境）

每种任务给「默认维度倾向 → 核心张力 → 典型选项」：

| 任务类型 | 常见维度 | 张力 | 场景例子 |
|---|---|---|---|
| 穿行 | 轻功/胆识/资源 | 过不过得去 | 渡河、攀崖、走索桥、踏冰 |
| 探寻 | 眼力/见识/苏唐 | 找不找得到、认不认得 | 山洞、密林、地宫、废村 |
| 交锋 | 武艺/口才/胆识 | 打得过还是谈得拢 | 劫镖、拦路、野兽、劫匪 |
| 市井 | 口才/眼力/资源 | 值不值、上不上当 | 讨价还价、黑市、赌局、酒馆 |
| 造化 | 见识/胆识/赌运 | 认不认得宝、取不取 | 奇遇、天材地宝、野味、古物 |
| 夜行 | 胆识/内功/时间 | 赶路还是停 | 天黑、涨潮、雨季、灯油将尽 |
| 协作 | 苏唐好感/苏唐手艺 | 信不信她、怎么分工 | 双人配合、她掌锅你探路 |

七大任务类型跟地图十据点的对应关系：探洞地宫→探寻，天灾→夜行，密林采山→探寻/穿行，
奇遇→造化，劫镖江湖→交锋，水域→穿行，市井→市井，节庆→协作，人情→协作，商贸→市井。
（这层映射先写死在 `EXPEDITION_MAP` 每个据点的 `category` 上，具体哪几类任务出现在
哪个据点，由据点的 `category` 决定候选任务类型池。）

## 第四层：选项类别库（决策的类型学）

任何一道题，选项都从这 8 种动作原型里长出来。每种绑定显示形态 + 判定 + 风险回报：

| 类别 | 玩家视角的选项长这样 | 判定 | 回报/代价 |
|---|---|---|---|
| 强攻 | 「拔刀，正面硬闯」 | 检武艺 | 高回报，失败伤血 |
| 巧取 | 「借石借力，翻身而上」 | 检轻功/投掷 | 中回报，失败落空不伤 |
| 智察 | 「先看清水流/灰烬/脚印」 | 检眼力/见识 | 成功解锁隐藏选项 |
| 口舌 | 「跟守林人套近乎」 | 检口才 | 成功省资源，失败降好感 |
| 资源 | 「解下包袱里的绳索」 | 无检定，直接扣 | 消耗道具/银钱 |
| 借苏唐 | 「喊苏唐搭把手」 | 检好感 + 苏唐手艺 | 消耗好感，苏唐长经验 |
| 回避 | 「算了，绕路走」 | 无检定 | 错过收获，可能耗时 |
| 赌运 | 「赌一把，闭眼跳」 | 纯骰子 | 高回报，高风险 |

**规则：**

- 每道题给 3-5 个选项，AI 从类别库里挑，至少 1 个"智察"类（让玩家有机会靠观察逆天
  改命）。
- 「赌运」每次最多 1 个，且永远是最便宜的文本（"赌一把"）。
- 「回避」永远存在——玩家任何时候都能转身走，这是探秘不失控的底线。

## 第五层：交互方式（玩家怎么出招）

| 交互 | 手感 | 触发场景 |
|---|---|---|
| 点选项 | 最普通，选完即判 | 所有题 |
| 骰子检定 | 点击后掷骰动画 + 成败飘字 | 强攻/巧取/赌运 |
| 智察先手 | 先点「观察」，成功再解锁 1-2 个隐藏选项 | 智察类前置 |
| 消耗确认 | 弹「要用掉一捆麻绳？」，可反悔 | 资源类 |
| 借力确认 | 「请苏唐帮忙，好感-3？」 | 借苏唐类 |
| 限时决策 | 选项倒计时消失（水漫到膝、灯油将尽） | 夜行/造化类 |

其中"智察先手"是灵魂：它把"读题干猜维度"变成机制——你猜这是眼力题，先观察，赌对了
多一条路，赌错了浪费一次行动机会。

## UI：左右两栏怎么分工

探秘进行中，左栏（`#log`）继续走主叙事（题干、判定结果的文学化描述），右栏
（`#sulog`，平时是苏唐日志）临时切换成选项面板：按钮形式列出当前可选的动作，点了就
判定、出结果。探秘结束（拿到收获或选择回避）后，右栏切回苏唐日志模式，不清空苏唐原本
的历史记录。

## 一局完整的探秘流程示意

```
探秘开始 → 引擎抽维度[眼力,胆识] → AI出题(只给文学题干)
  ↓
玩家看到题干："雾里影影绰绰，像是有什么东西在盯……"
  ↓ 玩家先点【智察】"蹲下，拨开雾看个仔细" → 检眼力 → 成功
  ↓ 解锁隐藏选项【认出是头饿了三天的独狼，它在虚张声势】
  ↓ 玩家选【口舌】"缓步后退，不露怯意" → 检胆识 → 成功
  ↓ 收获：★霜髓野菌 ×2，苏唐批一句，心情回落
```

玩家全程只知道"我在雾里遇到东西，我蹲下看了看，我猜它在虚张声势"——他赢了因为读懂了
题干，不是因为背下了数值。

      `src/data.js`）。「赌博」已并入 `DIMENSIONS`（心性组）并挂到市井/造化/协作任务
      类型，供骰子检定与成就使用。
- [x] 通用维度判定（`state.js` `checkDim`/`skillValueOf`）：骰子三围（见识/口才/赌博）
      走 `st.checks` 熟练度——`成功率 = 基础30% + 成功次数×5%（封顶90%）`，达成成就
      再永久 `+50%`（硬顶95%）；属性四维（轻功/投掷/武艺/内功/胆识）走 `st.skills`
      数值判定（武艺取刀剑拳枪最高，胆识取七艺均值），不计数。眼力并入见识。
- [x] AI 出题（`ai.js` `genChallenge`）：一次调用出「题干 + 选项 + 鉴定要求」。
      维度池从 `CATEGORY_TASK_TYPES → EXPEDITION_TASK_TYPES.dims` 推导，**覆盖全部
      可判定维度**（含属性维度，非止见识/口才/赌）；选项为文学化动作文本并绑定维度，
      题干/选项均不出现维度名、数值、成功率。无 Key 时走内置降级模板。
